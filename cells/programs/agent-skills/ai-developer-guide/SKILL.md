# AI Developer Guide

This is a local wrapper for [dwmkerr/ai-developer-guide](https://github.com/dwmkerr/ai-developer-guide).

1. Read the Golden Rules and Plan / Implement / Review sections of the bundled
   `README.md`, relative to this skill directory. Apply the phase the user asks
   for and respect the repository's own instructions.
2. Use the README's index to select relevant files under `guides/`; read only the
   guides that bear on the current decision. The docs update with the flake.
3. Report the plan, change, or findings for that phase. Treat setup examples as
   reference only; this wrapper needs neither an MCP nor a remote fetch.
